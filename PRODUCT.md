# AegisDR
<!-- impeccable:product-schema 1 -->
## Platform
web
## Stack
User-specified React, TypeScript, Vite, Tailwind, FastAPI, SQLAlchemy, SQLite metadata, optional PostgreSQL and Kubernetes.
## Users
Engineers demonstrating and operating local disaster recovery for containerized applications.
## Product Purpose
Create, verify and restore actual recovery points, with durable job history and honest health reporting.
## Operating Context
Local workstation first. Docker Compose and an optional isolated Kubernetes namespace. No paid services or remote publication.
## Capabilities and Constraints
Backups, retention, recovery, disposable simulations, application registration, metrics and audit history. Missing infrastructure must report unavailable. No fabricated metrics. No Git commits or pushes.
## Brand Commitments
AegisDR. Black-and-white dashboard with neutral grays, readable contrast, simple language, responsive layout, and smooth motion that respects device and user reduced-motion preferences.
## Evidence on Hand
The user's detailed build specification. No incumbent application or historical metrics.
## Product Principles
Verify before restore; isolate destructive demos; persist outcomes; distinguish observed values from targets.
## Accessibility & Inclusion
Keyboard-accessible controls, reduced motion, readable contrast.
